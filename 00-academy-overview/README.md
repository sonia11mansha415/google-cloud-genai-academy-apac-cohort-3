## 🧾 Documentation Standard

Every technical track moves through the same public record:

```text
Problem
  → Architecture
    → Implementation
      → Validation
        → Evidence
          → Limitations
            → Lessons
```

### What gets documented

- the problem the agent is meant to solve;
- the actual services and tool/data boundaries used;
- the implementation files that Sonia really executed;
- deployment and validation evidence;
- meaningful troubleshooting and final fixes;
- security decisions that are visible in the design;
- limitations and realistic enhancement ideas.

### What stays private

- participant dashboards and internal forms;
- quiz content;
- billing/credit/payment information;
- IAM/account administration history;
- secrets, API keys, tokens, credentials and service-account keys;
- private user or company data;
- repetitive progress screenshots that do not add technical evidence.
